# https://3vorp.github.io

slightly better formatted version of my github readme with like three useful tools

## currently featuring

- [gambling simulator](https://3vorp.github.io/gamble)
- mediocre mobile support
- sveltekit, scss, and typescript dependencies that are probably completely unnecessary (it's like 80% static content)
- [batch recolorer](https://3vorp.github.io/utils/recolor) which may or may not randomly break depending on whether your browser can handle images properly ([why is this a thing](https://stackoverflow.com/a/23501676/20327257))
- [text uwuifier](https://3vorp.github.io/utils/uwu) (I'm sorry)
- super cool reactive navbar and footer components please check them out they took me so long

## running the site locally (why would you want to do this)

- install [nodejs](https://nodejs.org) 20+ and [pnpm](https://pnpm.io/)
- run `pnpm i` to install the dependencies
- run `pnpm dev` to start a local dev server
- run `pnpm run deploy` to deploy the site to gh pages (idk why `pnpm deploy` doesn't work either)
